## 地形 v1 的关键发现（v2 为此而改）

1. **只在高速时会爬坡**：Isaac 里 30.4° 坡（第 8 级），0.6 m/s 时卡在坡底（12 s 只走 1.38 m），0.8 m/s 走 2.89 m，1.0 m/s 走 7.61 m 顺利通过。
   原因：障碍地形上的前进速度在 [−1, 上限] 里均匀采样，地形课程又会降级爬不动的机器人，所以高难度地形上几乎只有快速指令。
2. **v2 的改动**（`elbowdog_config.py` 的 `ElbowDogRoughCfg`、`elbowdog.py`）：
   - 障碍地形只给前进指令：`type_min_vx = 0.3`；
   - 新增 `forward_progress` 奖励（+0.5，实际前进速度 / 指令速度，限制在 0–1）；
   - 摆动脚目标离地高度 7 → 9 cm。
3. **旧的地形扫描判据太宽松**：`eval/terrain_sweep.json`（第 1200 次迭代、显示约 100%）作废。
   新判据从地块中心出发，沿 +x 前进 3.5 m 才算通过，输出 `eval/terrain_sweep_v<速度>.json`。
4. **sim2sim**：MuJoCo 默认软接触（solref 0.02）下，v1 只能过 25° 坡和 8 cm 台阶；接触改硬（`--solref 0.005`）后 10 cm 台阶能过。
   30° 坡在 MuJoCo 里任何接触设置都过不去（与 Isaac 低速卡住一致，是策略问题）。

评估和记录已完成，见 `docs/训练迭代记录.md` 第 2、3 轮。下面的命令是复现用的，不必再跑一遍，除非要换检查点。

## 复现命令（已跑过）

```bash
source ~/elbowdog_rl/env.sh
# 1. 等 v2 结束（不要同时开两个训练，GPU 吞吐会下降）
# 2. v1 基线与 v2 的严格地形扫描，每种 0.5 和 1.0 m/s
python scripts/play.py --task elbowdog_rough --load_run Nov09_18-23-02_v1 --checkpoint 1800 --mode terrain --v_cmd 0.5
python scripts/play.py --task elbowdog_rough --load_run Nov09_18-23-02_v1 --checkpoint 1800 --mode terrain --v_cmd 1.0
python scripts/play.py --task elbowdog_rough --load_run Nov09_19-31-16_v2 --mode terrain --v_cmd 0.5
python scripts/play.py --task elbowdog_rough --load_run Nov09_19-31-16_v2 --mode terrain --v_cmd 1.0
# 3. Isaac 单地块视频（答辩素材）：30° 坡、12 cm 台阶上/下
python scripts/play.py --task elbowdog_rough --load_run Nov09_19-31-16_v2 --mode tile --terrain_type slope_up  --level 8 --v_cmd 0.6
python scripts/play.py --task elbowdog_rough --load_run Nov09_19-31-16_v2 --mode tile --terrain_type stairs_up --level 7 --v_cmd 0.6
# 4. 导出 v2 → MuJoCo（默认接触和 --solref 0.005 各跑一遍，--tag 区分结果文件）
python scripts/play.py --task elbowdog_rough --load_run Nov09_19-31-16_v2 --mode demo      # 生成 exported/
cd sim2sim; P=../logs/elbowdog_rough/Nov09_19-31-16_v2/exported
for s in ramp20 ramp25 ramp30 stairs8 stairs10 stairs12 stairs14; do python deploy_mujoco.py --policy $P --scene $s --mode course --timeout 40; done
python deploy_mujoco.py --policy $P --scene course --mode course --video                  # 综合赛道视频
python deploy_mujoco.py --policy $P --scene flat --mode speed                             # 地形策略的平地速度
```

5. 判断：若 v2 在 0.5 m/s 下仍爬不上 30° 坡或 12 cm 台阶，可选
   (a) 继续微调 1000–2000 次（`--resume --load_run Nov09_19-31-16_v2`）；
   (b) 提高 `forward_progress` 到 1.0，或把 `tracking_sigma` 从 0.25 降到 0.15；
   (c) 从头训练 v3（`--run_name v3`，4000 次迭代，约 1.8 小时）。
6. 把地形 v1、v2 的设计、曲线（`python tools/plot_training.py <run> --out docs/figures/rough_v2_training.png`）、
   扫描表、MuJoCo 结果写进 `docs/训练迭代记录.md` 的第 2、3 轮，格式参照第 1 轮。
7. 可选改进（写在文档“后续工作”里即可）：低速步态不对称（0.5 m/s 时 FL/RR 占空比 0.6/0.74，FR/RL 只有 0.28/0.30），
   高速冲击力（足端力 99 分位 315 N，超过结构有限元的 300 N 筛查载荷）。
