# 环境复现

这是 2026-11-10 训出 v12 时那台机器上的完整 Python 环境清单。GitHub 不能放 5.3 GB 的 conda 目录，也不能转发 Isaac Gym 的安装包（NVIDIA 许可不允许再分发）。下面的文件可以把同一套包装回来。

| 文件 | 内容 |
|---|---|
| `environment.yml` | `conda env export` 的结果，Python 3.8.20 和全部 pip 包版本 |
| `requirements-runtime.txt` | `install.sh` 实际安装的运行依赖，版本与训练机一致 |
| `requirements-pip.txt` | 当时环境里其余已安装的普通包。同一个 conda 环境里还混有 ROS 2 命令行包，复现狗的策略不需要它们 |
| `pip-freeze.txt` | 当时 `pip freeze` 的原文。本机 editable 安装已改成注释 |
| `conda-explicit.txt` | conda 本体的 explicit 规格 |
| `install.sh` | 按上面的清单创建名为 `elbowdog` 的环境 |

训练机实际版本：Python 3.8.20，PyTorch 2.0.1+cu118，MuJoCo 3.2.3，TensorBoard 2.14.0，protobuf 4.25.8（2.14 和 protobuf 5 不兼容，曲线页面会空白）。

## 安装顺序

1. 安装 Miniconda，然后运行 `bash environment/install.sh`。
2. 从 <https://developer.nvidia.com/isaac-gym> 下载 **Isaac Gym Preview 4**（Python 包版本 `isaacgym==1.0rc4`），解压后执行：

   ```bash
   conda activate elbowdog
   pip install -e /path/to/isaacgym/python
   ```

3. 安装随仓库带上的两份未改过的依赖，提交号和训练时一致：

   ```bash
   pip install -e third_party/legged_gym    # commit 8fa29ac
   pip install -e third_party/rsl_rl        # tag v1.0.2, commit 2ad79cf
   ```

4. `source env.sh`。脚本会激活 `elbowdog`，并把 `LD_LIBRARY_PATH` 指到 conda 的 `lib`（否则 Isaac Gym 找不到 `libpython3.8.so`）。

GPU 是 NVIDIA，驱动要能跑 CUDA 11.8。训练用过 RTX 4090 Laptop 16 GB，`--headless`，约 4096 个并行环境。不要开 Isaac 窗口同时画几千个机器人，机器会卡死。

## 不在仓库里的东西

- Isaac Gym 安装目录。
- conda 环境本体（约 5.3 GB）。
- `logs/` 里每一轮的中间检查点（约 1.6 GB）。最优权重已经抽到 `best/v12/`。
